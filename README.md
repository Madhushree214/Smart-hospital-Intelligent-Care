# Smart hospital Intelligent Care
The Smart Hospital Management System is an advanced healthcare web application developed using React.js. It helps manage hospital operations digitally through modules like patient management, doctor scheduling, appointment booking, billing, pharmacy, and health analytics.  The system includes role-based access for Admin, Doctor, Receptionist, and Patient with secure authentication and responsive dashboards. It features modern UI/UX, interactive charts, dynamic data management, and reusable React components to simulate a real-world hospital management platform.
